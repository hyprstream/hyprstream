# `hyprstream` is deprecated

This Apache-2.0 `hyprstream` 0.5.0 package replaces the stale metrics crate
previously published under this name. It intentionally provides no product API,
service implementation, or runtime dependency.

For current Hyprstream installation guidance, see the
[project installation instructions](https://github.com/hyprstream/hyprstream#installation).
For current client guidance, see the
[OpenAI-compatible client/API instructions](https://github.com/hyprstream/hyprstream#openai-compatible-rest-api).

This shim must be published and verified from crates.io before the obsolete
versions are yanked.
